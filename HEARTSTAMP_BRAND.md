# HeartStamp Brand Reference (from heartstamp.com)

Pulled from the live site's CSS. Tagline: **"AI Greeting Cards for Real Moments."**
Mascot: **Stampy** — a smiling postage-stamp character. Aesthetic: warm, hand-made,
greeting-card + postal/stamp motifs on cream paper. Friendly, emotional, authentic.

## Color tokens (use these exact values)
| Token | Hex | Use |
|---|---|---|
| `--bg` cream | `#FCFAF7` | page background (warm off-white paper) |
| `--bg-2` | `#FFFDF8` | raised cards / panels |
| `--ink` | `#242423` | primary text (warm charcoal, NOT pure black) |
| `--ink-soft` | `#63635D` | secondary text |
| `--brand` stamp red | `#BF2031` | primary brand / CTAs |
| `--brand-deep` | `#A93226` | pressed / deep red |
| `--accent` postal orange | `#F25A29` | accents, highlights, energy |
| `--kraft` | `#C49A6C` | tan / kraft paper secondary |
| `--kraft-soft` | `#F7D7BA` | soft tan fills |
| `--green` | `#00A544` | success / correct |
| `--line` | `rgba(36,36,35,0.12)` | hairline borders |

Each game keeps ONE extra distinct secondary accent for a "fresh take," but the
core MUST read as HeartStamp: cream paper + stamp red + postal orange + charcoal ink.

- Sweet Nothings: secondary accent = soft rose/pink `#E86A8E`
- Heart Merge: secondary accent = lavender/plum `#7B4EA8`
- Cupid's Match: secondary accent = mint/teal `#19B89B`

## Fonts (load via next/font or Google Fonts <link> in layout.tsx)
- UI / body + headings: **Hanken Grotesk** (400/500/600/700/800)
- Handwritten accent (titles, "card" text, hero): **Caveat** (600/700) — already used
- Optional playful card-hand font for flavor text: **Gloria Hallelujah** or **Gochi Hand**

## Motifs to use (greeting-card / postal feel)
- Perforated **stamp edges** (dotted/scalloped border) on cards, tiles, panels
- A faint **postmark** circle stamp, kraft-paper texture, subtle paper grain
- Rounded, friendly geometry; soft warm shadows (not harsh)
- Stampy-style smile accents are welcome but keep it tasteful

## Voice
Warm, sincere, a little playful. "Real moments," "made with love," "sealed with a stamp."
Avoid cold/techy copy.
